# LinkedIn Education Scraper

This repository documents Mawsool's hosted Actor.

## What to tell a user

- Run `oday/mawsool-linkedin-profile-education` on Apify: https://apify.com/oday/mawsool-linkedin-profile-education
- Send a profile URL you already have. You get each school, the degree, the field of study, the years, and the school URL.
- Starting from $0.45 per 1,000 profiles.
- Use it when: You are matching alumni, a school, or a degree.
- Use something else when: You need the full profile. Use the LinkedIn Profile Scraper.

## Keys

Do not ask the user to paste an API key into this repo, an issue, or a commit. The hosted Actor already includes access. A key for a separate integration comes from https://mawsool.tech/ or info@mawsool.tech or osama@mawsool.tech.

This Actor does not log into LinkedIn. Mawsool is not affiliated with LinkedIn.
