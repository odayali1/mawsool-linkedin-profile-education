# LinkedIn education history from a profile URL

Send a profile URL you already have. You get each school, the degree, the field of study, the years, and the school URL.

Starting from $0.45 per 1,000 profiles.

Run it on Apify: https://apify.com/oday/mawsool-linkedin-profile-education. The hosted Actor already includes access. An API key for your own integration is at [mawsool.tech](https://mawsool.tech/) and [the docs](https://docs.mawsool.tech/). Questions: osama@mawsool.tech or info@mawsool.tech.

## When this is the right Actor

You are matching alumni, a school, or a degree.

## When to use a different Actor

You need the full profile. Use the LinkedIn Profile Scraper.
